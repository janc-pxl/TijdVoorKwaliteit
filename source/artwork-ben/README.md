# Ben voor de kwaliteitspagina

Dit pakket is input voor het aanpassen van:
https://janc-pxl.github.io/TijdVoorKwaliteit/kwaliteit.html

Geef `IMPLEMENTATIE.md` samen met de map `artwork/` aan de ontwikkelaar of coding agent die de website aanpast. De instructie bevat aanbevolen plaatsingen, feedbacktoestanden, optionele uitbreidingen, richtmaten en oplevercontroles.

De zes transparante PNG's bevatten de gecorrigeerde Ben zonder het kleine donkere baardvlekje onder de onderlip. De oorspronkelijke foto's zijn niet opgenomen.

`KARAKTERREFERENTIE.md` beschrijft het consistente uiterlijk en gebruik. `PROMPTS.md` bevat de generatie-instructies voor eventuele toekomstige poses. Ze zijn achtergrondinformatie; `IMPLEMENTATIE.md` is de opdracht voor de websiteaanpassing.

De zip wijzigt of publiceert de website niet. De aanbevolen plaatsingen vormen een voorstel; de optionele uitbreidingen zijn apart benoemd om te voorkomen dat Ben te veel aanwezig wordt.
