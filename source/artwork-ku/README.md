# Kwaliteit versus Uitwerking

Twee illustraties in de eerder gekozen papierstijl, met transparante achtergrond. Tekst en inhoudelijke indeling blijven behouden. index.html en stijl.css tonen de plaatsing: klein rechtsboven bij de termen, circa 145 × 100 pixels op desktop en 100 × 90 pixels op mobiel. Dit is een afzonderlijk voorstel; de live website is niet gewijzigd.

- artwork/kwaliteit.png: tandwiel, vergrootglas en controlemerk voor correcte werking.
- artwork/uitwerking.png: multitool voor de mogelijkheden van een product.

Kopieer de PNG-bestanden naar je afbeeldingsmap. Ze zijn decoratief bij de volledige tekst: gebruik alt="". Neem de relevante kaartstijlen over uit stijl.css; deze CSS is voor het losse voorbeeld bedoeld.

Gemaakt met het ingebouwde imagegen-gereedschap. Prompts staan in PROMPTS.md.
